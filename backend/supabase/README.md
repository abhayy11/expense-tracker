# Supabase Backend – Expense Tracker

## Purpose
This folder contains the backend implementation using Supabase.

## Features
- Secure storage for transactions
- User-based access using Supabase Auth
- Row Level Security (RLS)

## Tech Stack
- Supabase
- PostgreSQL
- Supabase Auth

## Environment Variables
- SUPABASE_URL
- SUPABASE_ANON_KEY
